# 更新履歴

アプリの「版(バージョン)」ごとに、何が変わったかを書く。新しい版を上に足していく。

## 版の付け方

- 形式は `大きな変更.機能追加.小さな修正`(例: `1.1.0`)
  - 大きな変更 … データの形が変わる、使い方が大きく変わる
  - 機能追加 … 画面やカードが増える・並びが変わる
  - 小さな修正 … 不具合直し・文言の修正
- 版を上げるときに変える場所は3つ(`node scripts/check-version.js` で食い違いを確認できる)
  1. `index.html` の `APP_VERSION`
  2. `sw.js` の `VERSION`(キャッシュ名にもなる。上げ忘れると古い画面が出続ける)
  3. このファイルに新しい版の見出しを足す
- 公開したら、Gitに同じ名前の目印(タグ `v1.1.0` など)を付ける。昔の版に戻したいときの目印になる
- アプリの設定タブ「アプリについて」に、いま動いている版が表示される

## 1.3.0(2026-11-08)

「いま使えるお金」がほんとうの残高とずれたときに、自分で合わせられるようにした。

- 集計の「いまの残高」に「ほんとうの残高にあわせる」ボタンを追加。口座ごとにほんとうの金額を入れると、差の分を「残高あわせ」として記録する(支出・収入・記録日数・連続記録には入らない)
- 振替先に「ちょきん(べつの口座)」を追加。毎月1日にべつの口座へ移したお金を記録できる。移したお金は「いま使えるお金」から引かれ、「いまの残高」に別枠で出る
- 中身: 記録の種類に `adjust`(残高あわせ。金額はマイナスもある)、振替先に `saving` を追加

## 1.2.0(2026-11-07)

- 履歴タブを月ごとに表示するようにした(‹ › で月を選ぶ)。上にその月の記録件数・収入・支出を表示。これまでの「直近200件まで」の制限はなくなった
- 入力タブ上の帯の数字を大きくした。「いま使えるお金」を1段目に大きく(40px)、「今月つかった」「今週の記録」を2段目に(26px)。一目で読めるように
- ほかのページの数字も大きく・太くした(集計の月末残高・収支 28px、収入・支出・記録日数 20px、内訳の金額 18px、支出ごうけい 22px、口座の残高 22px、履歴の金額 19px、棒グラフの目盛り)
- 履歴のメモを、HTMLとして解釈せず文字のまま表示するようにした(安全のため)

## 1.1.0(2026-11-06)

UX5段階モデルに合わせて、画面を「問い」ごとに整理した。

- 集計タブを「いくら残ってる? → どこに使った? → 前の月とくらべて? → いまの残高」の順に並べ替え
- 「カテゴリーべつ」と「支払い方法べつ」を、切り替えボタン付きの1枚「どこに使った?」にまとめた。円グラフはカテゴリーのときだけ出る
- 入力タブの上に「いま使えるお金/今月つかった/今週の記録」の帯を追加
- 記録したときのほめ言葉に「今週は◯日も記録できたね!」を追加
- 設定タブに「アプリについて」(版の表示と、新しい版の確認ボタン)を追加
- 中身: 内訳リストを共通部品(`DIMENSIONS` + `renderBreakdown`)にした
