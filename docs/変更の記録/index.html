かんたん家計簿 / 変更の記録

作った日から、いままでのあゆみ

アプリの画面が、版ごとにどう変わってきたかの記録です。どの版にも同じサンプルの金額を入れて撮っているので、見た目のちがいだけをくらべられます(お子さんの本当の記録ではありません)。

2つの版をくらべる

左と右で版を選び、見たい画面を選んでください。画像を押すと大きく表示します。

版ごとの変更点

新しい版が上です。画像は横にスクロールできます。

新しい版を記録するには

  1. 版を上げて公開したら、Claudeに「変更の記録に今の版を追加して」と頼む
  2. Claudeがサンプルの金額(scripts/capture-demo.js)を入れて4枚の画面を撮り、img/ に保存する
  3. このファイルの VERSIONS の先頭に、版・日付・変更点を1件足す
